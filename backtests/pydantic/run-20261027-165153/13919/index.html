Description

PEP 728 support was added in #12179, but a few cases from the spec don't work.

  1. extra_items isn't inherited. A subclass of a TypedDict with extra_items=int

should also accept extra int items. Pydantic treats the subclass as a plain TypedDict
and silently drops the extra keys.

  1. closed=True isn't inherited. A subclass of a closed TypedDict should also reject

extra keys. Pydantic accepts them and drops them instead of raising extra_forbidden.

This also affects JSON schema: the parent gets "additionalProperties": false,
the subclass doesn't.

  1. extra_items=Never and extra_items=ReadOnly[int] raise

PydanticSchemaGenerationError. The PEP says extra_items=Never is the same as
closed=True, and allows extra_items to be wrapped in ReadOnly[].

For 1 and 2, I think the cause is that _generate_schema.py reads __closed__ and
__extra_items__ directly from the class. Per the PEP, those attributes only reflect
what was passed to that exact class, not its parents. TypedDict parents also aren't
in __mro__, only in __orig_bases__, so finding the inherited value means walking
those.

For 3, extra_items is passed straight to generate_schema without handling
Never or unwrapping ReadOnly.

I'd like to work on a fix for this if that's okay.

Example Code

import json
from typing import Never

from typing_extensions import ReadOnly, TypedDict

from pydantic import TypeAdapter


class Parent(TypedDict, extra_items=int):
    a: str


class Child(Parent):
    pass


print(TypeAdapter(Parent).validate_python({'a': 'x', 'b': '1'}))
# {'a': 'x', 'b': 1}
print(TypeAdapter(Child).validate_python({'a': 'x', 'b': '1'}))
# {'a': 'x'}  expected {'a': 'x', 'b': 1}


class ClosedParent(TypedDict, closed=True):
    a: str


class ClosedChild(ClosedParent):
    pass


print(TypeAdapter(ClosedChild).validate_python({'a': 'x', 'b': 1}))
# {'a': 'x'}  expected ValidationError

print(json.dumps(TypeAdapter(ClosedParent).json_schema()))
# includes "additionalProperties": false
print(json.dumps(TypeAdapter(ClosedChild).json_schema()))
# missing "additionalProperties": false

TypeAdapter(TypedDict('TD', {'a': str}, extra_items=Never))
# PydanticSchemaGenerationError
TypeAdapter(TypedDict('TD', {'a': str}, extra_items=ReadOnly[int]))
# PydanticSchemaGenerationError
