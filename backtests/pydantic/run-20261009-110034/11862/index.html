Cannot use model_dump(include=...) with @model_serializer (raises PydanticOmit)

Better

Our patch was judged better than the merged fix.

In this judgment, Patch A = our agent, Patch B = the merged fix.

Patch A fixes the reported problem. Calling `handler(self, info)` inside a wrap serializer is common, and the old docs example even used it. With A, `SerializationCallable.__call__` ignores a `SerializationInfo` passed as the second argument instead of treating it as an include/exclude key. That key lookup is the root cause of the spurious `PydanticOmit`. The issue's exact example then works with `include` and `exclude`, and the handler still applies the serializer's own current filter state. A's tests would fail before the change and pass after it. They cover the issue's model_serializer case, a field_serializer case with nested include/exclude, and a pydantic-core-level dict schema test, in both Python and JSON modes. The change is small and well commented. Patch B does not fix the issue. The issue's code (`handler(self, info)`) would still fail, now with a TypeError ('index_key is expected to be an integer or a string') instead of PydanticOmit. B effectively declares the user pattern invalid and rewrites the WrapSerializer docs example to stop passing `info`. B also adds risk: restricting `key_filter` to str/int may reject other hashable dict keys that worked before, such as tuples or enums. B's only test checks that passing bytes raises a TypeError, which says nothing about the reported scenario. A is clearly better on correctness, tests and scope.

The judge saw only the two patches, labelled A and B in random order, with issue links and version numbers removed. The reasoning above is shown verbatim.

Description

Attempting to use the include parameter to model_dump when the model has a @model_serializer method causes a PydanticOmit exception to be returned.

Example Code

from pydantic import BaseModel, model_serializer

class Foo(BaseModel):
    bar:int
    baz:int

    @model_serializer(mode='wrap')
    def _serialize(self, next_serializer, info):
        return next_serializer(self, info)

f = Foo(bar=123, baz=456)

print(f.model_dump(include={'bar'}))
