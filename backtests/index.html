How Our Software Factory Compares

We replay real, already-fixed GitHub issues from public repos. Our software factory gets the issue and the code as it was before the fix, works in an isolated container with the network locked down, and never sees the real fix. A blind judge then compares our patch to the one maintainers merged, labelled only A and B.

How to read a verdict

Better

Our patch passes the full test suite and the judge preferred it to the merged fix.

Par

Both are equally good.

Worse

The merged fix was better, or our patch broke a test that passed before. We show every one.

Error

The harness couldn't finish the ticket. Counted in the total, never dropped.
