The issue

View on GitHub

The --lang flag help says "Defaults to the first language defined", but when
the flag is empty the command uses the default content language:

https://github.com/gohugoio/hugo/blob/master/commands/config.go#L74-L76

These differ when defaultContentLanguage is not first by weight.

Suggested text: "the language to display config for (default is the default content language)"
