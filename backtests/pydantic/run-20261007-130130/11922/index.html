Some Field attributes lost in JSON schema when using RootModel

Better

Our patch was judged better than the merged fix.

In this judgment, Patch B = our agent, Patch A = the merged fix.

Both patches add `examples` and `deprecated` from the RootModel `root` field to the schema, and both let a field title override the class name. They differ in edge-case correctness. Patch A reads `cls.__pydantic_fields__['root'].title` without checking where the title came from. Pydantic's `field_title_generator` can write a generated title (e.g. 'ROOT') onto the field info, and A would then wrongly replace the class-name title with it. Patch B uses the root title only when it is in `_attributes_set`, i.e. explicitly set, and adds a test (`test_model_with_field_title_generator`) for exactly that case. B also handles `deprecated=''`, which is falsy but still deprecated; A's plain truthiness check misses it. B adds the deprecated flag next to the existing `__deprecated__` handling, keeping the logic in one place. B computes `root_field` once and reuses it for description, examples, title and `json_schema_extra`, which removes duplicated lookups and the extra `RootModel` issubclass checks. B's tests are broader: a nested model with non-JSON-native examples (date serialized via `to_jsonable_python`), a deprecated message string, a config-title override, and the generator case. A's tests cover the basic cases only. Neither patch adds risky churn. B is the more robust and better-tested fix.

The judge saw only the two patches, labelled A and B in random order, with issue links and version numbers removed. The reasoning above is shown verbatim.

Description

When declaring a RootModel and adding a Field annotation to the root property that includes examples, those examples are not part of the generated JSON schema. This also applies to the deprecated attribute. The title attribute is also not applied or it is overwritten by the class name of the root model class.

Most other attributes, such as pattern or description are exposed as expected. Furthermore, placing examples in json_schema_extra also works as expected.

Example Code

from typing import Annotated
from pydantic import RootModel, Field

class Foo(RootModel):
    root: Annotated[str, Field(examples=["foo", "bar"], deprecated=True)]

print(Foo.model_json_schema())  # does not include examples or deprecated.
