Initial Checks

Description

When the variadic keyword parameter of a function is annotated with an unpacked TypedDict, validation treats the items of the typed dictionary as individual keyword arguments, but the JSON Schema generated for the function arguments puts the whole typed dictionary under additionalProperties, as if the annotation were **kwargs: Options.

For the example below the schema is:

{
    '$defs': {
        'Options': {
            'properties': {
                'timeout': {'title': 'Timeout', 'type': 'integer'},
                'label': {'title': 'Label', 'type': 'string'},
            },
            'required': ['timeout'],
            'title': 'Options',
            'type': 'object',
        }
    },
    'additionalProperties': {'$ref': '#/$defs/Options'},
    'properties': {'name': {'default': 'job', 'title': 'Name', 'type': 'string'}},
    'type': 'object',
}

So the schema and the validator disagree in both directions:

keyword argumentsvalidationJSON Schema
{'name': 'x', 'timeout': 5}acceptedinvalid (5 is not of type 'object')
{'name': 'x'}rejected (missing)valid
{'anything': {'timeout': 5}}rejected (missing)valid

I would expect timeout and label to be listed in properties (and timeout in required), with additionalProperties following the typed dictionary (closed / extra_items).

GenerateJsonSchema.arguments_schema() forwards var_kwargs_schema to kw_arguments_schema() without checking var_kwargs_mode, so 'unpacked-typed-dict' is handled like 'uniform' (pydantic/json_schema.py, arguments_schema() / kw_arguments_schema()). arguments_v3_schema() does distinguish the two modes. The validation side was added in #10416, which did not change json_schema.py.

I searched issues, PRs and discussions for Unpack TypedDict kwargs json schema, var_kwargs_mode, unpacked-typed-dict and kw_arguments_schema and did not find this reported; #11571 and #11572 extended the validation side and the experimental arguments schema without touching json_schema.py.

I have a small fix with tests ready and can open a PR if this is confirmed.
