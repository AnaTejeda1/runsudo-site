I have a simple testcase which is expected to fail (xfail)

@pytest.fixture
def my_fix():
    yield
    raise Exception()

class TestMyFix:
    @pytest.mark.xfail(reason="Some reason")
    def test_1(self, my_fix):
        raise Exception()

which is deliberately raising Exception and the fixture is raising it too

The test execution summary reports 2 testcases even when it collects 1 item

  Some reason

Without xfail it correctly report 1 error in teardown
