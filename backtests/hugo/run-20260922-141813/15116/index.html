Summary

What was wrong: hugo env printed the libwebp WASM dependency version but omitted the three AVIF-related C libraries (aom, dav1d, libavif) that are also embedded via WASM. common/hugo/hugo.go's GetDependencyListNonGo() only listed libwebp.

What I changed:

  • common/hugo/hugo.go — added three unconditional entries to GetDependencyListNonGo() (right after libwebp, since all four are WASM-embedded in every build, not extended-only), using the existing formatDep helper:
  • aomedia.googlesource.com/aom = v3.14.1
  • code.videolan.org/videolan/dav1d = 1.5.3
  • github.com/AOMediaCodec/libavif = v1.4.1
  • common/hugo/hugo_test.go — added TestGetDependencyListNonGoAVIF, asserting all three exact rendered strings (path="version") appear in the output.

I sourced the authoritative versions from internal/warpc/genavif/Makefile (LIBAVIF_VERSION=v1.4.1, AOM_VERSION=v3.14.1, DAV1D_VERSION=1.5.3) and the module paths from that Makefile's clone URLs. Note the ticket's proposed libavif="v.14.1" was a typo — the correct version is v1.4.1.

Test evidence:

  • Before the fix: TestGetDependencyListNonGoAVIF FAILED — no matching element found, container held only libwebp.
  • After the fix: ./bt-test ./common/hugo/ → all pass, including the new test and the 4 pre-existing tests (ok github.com/gohugoio/hugo/common/hugo 0.077s).
