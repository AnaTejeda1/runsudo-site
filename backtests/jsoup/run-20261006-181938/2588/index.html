The issue

View on GitHub

Since Jsoup version 1.18.1, when parsing input parameters, it performs fuzzy matching on the string following '&' against HTML entities and automatically converts them to HTML entities. For example, when a parameter contains '&timestamp=', it fuzzy-matches to '&times' and automatically converts it to '×' (multiplication sign). When a parameter contains '&param', it fuzzy-matches to '&para' and converts it to the paragraph symbol (¶). This causes input validation to fail. Before version 1.18.1, Jsoup would automatically convert '&' to '&', which was fine. However, after the upgrade, it performs fuzzy matching that incorrectly matches HTML entities that should not be matched. I believe this is a bug.

Jsoup 自从1.18.1之后会把入参的&后面的字符串进行模糊匹配html并自动转换为html的实体，例如传参涉及&timestamp=会模糊匹配到&times自动转成*，传参涉及&param会模糊匹配到&para自动转成段落符号;导致入参失败，1.18.1之前是会将&自动转成&amp;这是没问题的，但是升级之后会导致模糊匹配到不应该匹配的html实体格式，我理解这是个bug
