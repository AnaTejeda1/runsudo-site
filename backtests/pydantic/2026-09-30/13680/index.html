Description

Generic BaseModel parametrized with Self produces recursive schema loop.

Minimal reproduction below. Expected the call to succeed (or the schema to be correct), but instead pydantic raises. This worked on the previous minor release, so it looks like a regression in generics.

Related discussion: <link>

Example Code

from pydantic import BaseModel, Field, validate_call


class Model(BaseModel):
    value: int = Field(default=0)


def check(model: Model) -> None:
    print(model.model_dump())


check(Model(value=1))
# -> raises in generics
