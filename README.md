# runsudo.dev

The company site for sudo. One static page, no build step, served by GitHub Pages at the
custom domain in `CNAME`.

- `index.html` is the whole site. Edit and push to deploy.
- The waitlist form posts to Formspree: replace `YOUR_FORM_ID` in `index.html` after creating a form.
- When a sample report exists, drop it in as `report.html` and link it from the hero.
