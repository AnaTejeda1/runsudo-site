The issue

View on GitHub

I bumped into this odd edge case while importing some old technical documentation.

XML system literals in a doctype can use either single or double quotes as their delimiter.

jsoup accepts the valid XML below, but DocumentType currently always serializes the system identifier using double quotes:

String xml = "<!DOCTYPE root SYSTEM 'a\"b.dtd'><root />";
Document doc = Jsoup.parse(xml, "", Parser.xmlParser());

System.out.println(doc.outerHtml());
// <!DOCTYPE root SYSTEM "a"b.dtd"><root />

Escaping the quote as &quot; doesn't work because entity references are not interpreted inside a system literal; it would change the identifier’s value. Converting it to %22 would also change the stored identifier, and the XML external-identifier specification says URI escaping should happen only when necessary and as late as possible during dereferencing.

The fix will be to continue using double quotes normally, but use single quotes when the system identifier contains a double quote.
