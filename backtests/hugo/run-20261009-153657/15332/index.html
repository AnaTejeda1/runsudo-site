The issue

View on GitHub

This would be symmetrical with the existing strings.FirstUpper function.

Current:

{{ $s := "Hello" }}
{{ print (strings.Substr $s 0 1 | strings.ToLower) (strings.Substr $s 1) }}

Desired:

{{ $s := "Hello" }}
{{ $s | strings.FirstLower }}

This proposal stems from some work on the docs site. In addition to the syntax improvement, this is about 2x faster.
