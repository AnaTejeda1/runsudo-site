B also fixes several things the Go 1.27 move actually breaks or needs:
- In warpc, it ignores ErrShutdown during dispatcher shutdown. The comment says that since Go 1.27 (json/v2), Decode surfaces the read error from closed pipes. Without this, shutdown would return an error. A has no equivalent, so A may leave a runtime or test regression under 1.27.

B has downsides:
- Its test files lose gofmt/goimports formatting, though this matches upstream's style.
- It bumps Alpine to 3.24 without being asked.
- It includes some lint-ignore churn.

These are cosmetic or low-risk. On correctness and completeness of the Go 1.27 upgrade, B is meaningfully stronger.
