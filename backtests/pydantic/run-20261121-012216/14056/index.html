Description

ByteSize.human_readable() picks the unit by checking abs(num) < divisor on the unrounded value, and then prints the value with one decimal. A size just below the next unit passes the check but rounds up to the divisor when printed, so ByteSize(1048575), one byte short of 1 MiB, is shown as 1024.0KiB instead of 1.0MiB.

This happens at every unit boundary from KiB to PiB, in binary and decimal mode and with separator. It also happens on main at 03c7e0fb6.

Choosing the unit from the rounded value, round(abs(num), 1) < divisor, fixes it.

Example Code

from pydantic import ByteSize

print(ByteSize(1048575).human_readable())
#> 1024.0KiB (expected 1.0MiB)
print(ByteSize(999_999).human_readable(decimal=True))
#> 1000.0KB (expected 1.0MB)
