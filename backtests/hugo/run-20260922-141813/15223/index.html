Summary

What was wrong: The --lang flag on hugo config had help text reading "the language to display config for. Defaults to the first language defined." This is inaccurate: when --lang is empty, the command uses the default content language (commands/config.go:74-76 reads conf.configs.Base.DefaultContentLanguage), not the first language by weight. These differ whenever defaultContentLanguage is not the first-defined language.

What I changed:

  • commands/config.go:119 — updated the --lang flag usage string to the report's suggested text: "the language to display config for (default is the default content language)".
  • testscripts/commands/config.txt — added a regression assertion (stdout 'default is the default content language') to the existing hugo config -h block, run by TestCommands in main_test.go.

Test evidence:

  • Before the code change: the new assertion FAILED — no match for 'default is the default content language' found in stdout (testscripts/commands/config.txt:5).
  • After the code change: ./bt-test . -run TestCommands/config → 10 pass, 0 fail. The regression assertion now passes and no previously-passing assertion regressed.
