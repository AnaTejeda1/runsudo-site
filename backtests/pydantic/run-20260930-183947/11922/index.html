Some Field attributes lost in JSON schema when using RootModel

Better

Our patch was judged better than the merged fix.

In this judgment, Patch B = our agent, Patch A = the merged fix.

Both patches fix the core bug: RootModel now carries the root field's examples, deprecated flag and title into the model-level JSON schema. Patch B handles the edge cases more carefully.

1. **Title from `field_title_generator`.** Pydantic can fill in `FieldInfo.title` from a `field_title_generator`. Patch A reads `root_field.title` without checking where it came from, so a generated root title (e.g. 'ROOT') would silently replace the class-name title. Patch B only uses a title the user set explicitly (checked via `_attributes_set`), and it has a test proving generated titles don't leak.
2. **Title precedence.** In Patch A the root title applies only when neither the config title nor `model_title_generator` produced one. So an explicit `Field(title=...)` loses to a model-wide generator. Patch B gives the explicit field title precedence over the generator but not over an explicit config title, which is more sensible, and tests both orderings.
3. **Empty deprecation message.** Patch A uses `if root_field.deprecated:`, so `deprecated=''` (a valid empty-message form) is dropped. Patch B handles it and parametrizes a test for it.
4. **Placement of `deprecated`.** Patch B puts the flag in the existing `__deprecated__` block, consistent with how class-level deprecation is emitted.
5. **Tests.** Patch B also covers the nested `$defs` case, which confirms the metadata appears where RootModels are actually referenced.

Patch A's tests cover the basic scenarios but miss these edges. Both are similar in scope, and Patch B also lightly refactors `root_field` into one variable, which reads cleanly.

The judge saw only the two patches, labelled A and B in random order, with issue links and version numbers removed. The reasoning above is shown verbatim.

Description

When declaring a RootModel and adding a Field annotation to the root property that includes examples, those examples are not part of the generated JSON schema. This also applies to the deprecated attribute. The title attribute is also not applied or it is overwritten by the class name of the root model class.

Most other attributes, such as pattern or description are exposed as expected. Furthermore, placing examples in json_schema_extra also works as expected.

Example Code

from typing import Annotated
from pydantic import RootModel, Field

class Foo(RootModel):
    root: Annotated[str, Field(examples=["foo", "bar"], deprecated=True)]

print(Foo.model_json_schema())  # does not include examples or deprecated.
