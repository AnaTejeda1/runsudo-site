What the agent reported

The fix is complete and the gate passes. Here's my final report.

What was wrong

Hugo's js.Build generates assets/jsconfig.json via resources/jsconfig/jsconfig.go. When a source root is at or below the build directory, filepath.Rel produces path values like "*" or "sub/assets/*" — values that don't begin with ./ or ../. VS Code's TypeScript language service flags these: "Non-relative paths are not allowed when 'baseUrl' is not set. Did you forget a leading './'?"

Adding baseUrl — the other remedy the lint suggests — is explicitly forbidden here: the existing TestJsConfigBuilder asserts the marshaled JSON does not contain "baseUrl" (referencing issue 14991). So the correct fix is the lint's first suggestion: make the path values relative with a leading ./.

What I changed

resources/jsconfig/jsconfig.go — in Builder.Build, after computing each rel path, prefix it with ./ unless it is already a parent reference (.. or ../…), which is already relative. Added strings to imports. The guard uses a path-component check (rel != ".." && !strings.HasPrefix(rel, ".."+string(filepath.Separator))) rather than a bare substring prefix, so a descendant directory whose name legitimately begins with .. (e.g. ..cache) is still correctly prefixed. OS-native separators are preserved (no ToSlash), so existing filepath.FromSlash(...) expectations hold on all platforms. No baseUrl field was added.

resources/jsconfig/jsconfig_test.go — new TestJsConfigBuilderRelativePaths covering the reported scenario (source root == build dir → ./*) plus a descendant case (./sub/assets/*). The existing TestJsConfigBuilder, including its baseUrl negative assertion, is untouched.

Test evidence

  • Before the fix, TestJsConfigBuilderRelativePaths failed: got ["*"], want ["./*"] — confirming it captures the bug.
  • After the fix, ./bt-test ./resources/jsconfig/: TestJsConfigBuilder PASS, TestJsConfigBuilderRelativePaths PASS, package ok (0.008s). Verified from test-report.json.

Requirements checklist

  1. Fix the VS Code lint on jsconfig.json line 5 ("*" non-relative path) — Implemented. Non-relative values now get a ./ prefix ("*" → "./*"); regression test asserts the outcome and passes only after the change.
