Question

Hi, I’m using Pydantic AI’s OpenAIResponsesModel and providing an input prompt via the instructions parameter. In the OpenAI Logs dashboard, requests generated with that code always have their instructions labeled as “System instructions” at the top.

But when I run the same instructions via the OpenAI Playground / Prompt dashboard, it shows up in the logs labeled as “Developer” at the top.

OpenAI’s latest docs also seem to emphasize “developer” instructions for app-level behavior (rather than "system"), which makes it seem like the best practice for their API is to set "role": "developer" for instructions like these, I think?

Is there a setting or hook in OpenAIResponsesModel to send these as developer instructions (or otherwise match the Playground behavior)? If not, would you consider adding one, or documenting the current behavior and recommended workaround?

Ultimately, I'd like to be able to test/optimize prompts in the playground, and then have my Pydantic AI agents in my application send requests to the API that have identical configuration as the ones I'm tweaking in the playground.

Thanks for reading!
