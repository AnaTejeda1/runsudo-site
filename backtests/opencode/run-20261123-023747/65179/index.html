The issue

Description

This is a regression. The same setup was very fast on 2.1 and 2.2 series; the problem only appeared after updating to current version 2.3.2.

Four symptoms, all new:

  1. Slow initial load + UI freeze. Opening the model list — either in a new conversation or to change the model in an existing one — always takes 8+ seconds before the model dialog appears, and the interface freezes during that delay.
  2. Slow filtering. Typing in the search box of the model list is equally slow: every keystroke that filters the list takes 8+ seconds of response and blocks the interface (the UI freezes while it filters).
  3. Slow dialog update. Mouse over any of the models once the dialog is open causes a several seconds delay also with UI freeze, before finally displaying the reasoning efforts available.
  4. CPU spike during these freezes. While the interface is frozen, CPU usage spikes sharply. This looks like the same root cause that makes the list take so many seconds to appear and update — the four symptoms seem to be coming from the same problem.

Providers: I have two providers with many models available (OpenCode and CommandCode), plus 2 local providers with 6 models each. However, before (with versions 2.2.x and 2.1.x) it was very fast to open and filter the model list, with exactly the same providers and model count.

Expected Behavior

The model list should open quickly without freezing the UI, and filtering should update almost immediately as I type, as it did on previous versions.

Actual Behavior

Opening the model list freezes the interface for 8+ seconds, CPU usage spikes during the freeze, and each keystroke in the search box blocks the UI for 8+ seconds before the filtered list updates.

Additional context

  • Regression range: works well on 2.1.x and 2.2.x, broken on 2.3.2.
  • The CPU spike and the freeze occur at the same time, which suggests they share a single cause.
  • Possibly related: #64570 (desktop model picker stutter on hover/scroll) and #62583 (laggy model settings and slow search with many models).
