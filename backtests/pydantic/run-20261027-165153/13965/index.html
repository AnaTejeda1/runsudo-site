Initial Checks

Description

When a validator comes before Field(max_digits=..., decimal_places=...) in Annotated, the constraints are applied by the Python fallback in _validators.py instead of pydantic-core. That fallback never checks the number of digits before the decimal point, so values that the core rejects with decimal_whole_digits are accepted.

Expected: the same decimal_whole_digits error in both cases.

I have a small fix with tests (pass max_digits to decimal_places_validator and apply the core's whole-digits rule there) and would be happy to open a PR if this can be assigned to me.

Example Code

from decimal import Decimal
from typing import Annotated

from pydantic import AfterValidator, Field, TypeAdapter

plain = TypeAdapter(Annotated[Decimal, Field(max_digits=3, decimal_places=2)])
after = TypeAdapter(Annotated[Decimal, AfterValidator(lambda v: v), Field(max_digits=3, decimal_places=2)])

plain.validate_python('12.3')  # ValidationError: decimal_whole_digits
after.validate_python('12.3')  # Decimal('12.3'), no error
