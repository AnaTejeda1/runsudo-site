Mypy internal error when subclassing a generic model with a recursive type variable

Better

Our patch was judged better than the merged fix.

In this judgment, Patch B = our agent, Patch A = the merged fix.

The production fixes are functionally identical. Both import `has_placeholder` from `mypy.semanal_shared`. When a collected field's type still contains a placeholder, both call `self._api.defer()` (unless on the final iteration) and return False. That avoids serializing an unresolved `PlaceholderType`, which is the root cause of the assertion in `field.serialize()`, and lets mypy resolve the self-referential `Child` on a later pass. A folds the check into the existing `field.type is None` condition; B keeps it as a separate branch. That is only a cosmetic difference.

The tests are where they differ. A appends a case to the existing `generics.py` module, but uses `TypeVar(..., bound='Element')` with a string forward reference. That differs from the issue, which binds to the already-defined class `Element`. It also checks only `Child(children=[Child()])` and the `children` type. B adds a dedicated module and registers it in the test case list. It reproduces the issue's exact setup (`bound=Element`) and also covers `model_construct` and a further subclass (`GrandChild`) that inherits the placeholder-mapped field and adds its own field. Both tests would crash before the fix and pass after it, but B's case is a more faithful reproduction and exercises more of the plugin's paths (`__init__`, `model_construct`, multi-level inheritance).

Scope is minimal and equivalent in both. B wins on test quality.

The judge saw only the two patches, labelled A and B in random order, with issue links and version numbers removed. The reasoning above is shown verbatim.

Description

When using mypy with the pydantic.mypy plugin and a pydantic model that:

  • inherits from a generic model with a TypeVar bound to a BaseModel subclass,
  • has a self-referential type hint (e.g., Child referencing itself through Generic[_T]).

Example Code

from typing import Generic, TypeVar

from pydantic import BaseModel


class Element(BaseModel):
    pass


_T = TypeVar("_T", bound=Element)


class ElementWithChildren(Element, Generic[_T]):
    children: list[_T] = []


class Child(ElementWithChildren["Child"]):
    pass
