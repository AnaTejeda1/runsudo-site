Description

When declaring a RootModel and adding a Field annotation to the root property that includes examples, those examples are not part of the generated JSON schema. This also applies to the deprecated attribute. The title attribute is also not applied or it is overwritten by the class name of the root model class.

Most other attributes, such as pattern or description are exposed as expected. Furthermore, placing examples in json_schema_extra also works as expected.

Example Code

from typing import Annotated
from pydantic import RootModel, Field

class Foo(RootModel):
    root: Annotated[str, Field(examples=["foo", "bar"], deprecated=True)]

print(Foo.model_json_schema())  # does not include examples or deprecated.

What the agent reported

Done. Two files changed, both intentional.

What was wrong

For a RootModel, the root field's core-schema metadata (which normally carries title, examples, deprecated) is deliberately discarded during core-schema generation (_generate_schema.py:842-844), and only description was re-added afterward in _update_class_schema. As a result:

  • examples and deprecated from Field(...) on root were silently dropped from model_json_schema().
  • title from the field was overwritten by the unconditional class-name fallback (json_schema['title'] = cls.__name__).

pattern survived because it's baked into the inner str core schema; description survived via its own re-add special-case.

What I changed (pydantic/json_schema.py, _update_class_schema)

Extended the existing RootModel re-add pattern (localized here rather than touching core-schema generation, to avoid disturbing docstring/description precedence and json_schema_extra handling):

  • title: before falling back to the class name, use the root field's .title if set (still after config-title / model_title_generator, which take precedence).
  • examples: json_schema.setdefault('examples', to_jsonable_python(root_field.examples)).
  • deprecated: setdefault('deprecated', True) using the same normalization (bool(...) or ... == '') that normal fields use in _extract_json_schema_info_from_field_info.

All additions are gated on issubclass(cls, RootModel), so BaseModels, dataclasses, and TypedDicts are unaffected. Also updated the method docstring to list examples.
