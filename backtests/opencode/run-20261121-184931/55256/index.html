The issue

View on GitHub

Version: OpenCode 2.0.26 (checked against v2 @ 4617210822)

Description
Locale.number formats values from 999,950 to 999,999 as 1000.0K. The >= 1000000 check runs before rounding, so these values go to the K branch, where toFixed(1) rounds them up to 1000.0.

Evidence (v2 source)
packages/tui/src/util/locale.ts:19-26: num >= 1000000 → M; otherwise (num / 1000).toFixed(1) + "K".

Repro
Locale.number(999_950) returns "1000.0K"; the expected value is "1.0M". In the UI, this shows up in the token/context counters when a session is about 1M tokens in.
