In this judgment, Patch B = our agent, Patch A = the merged fix.

Both patches fix the three reported gaps (examples, deprecated, title) and pass every independent test. The difference is at the edges. Patch A reads `cls.__pydantic_fields__['root'].title` without distinguishing an explicitly set title from one injected by `field_title_generator` (pydantic writes generated titles back onto FieldInfo during core schema generation), so a RootModel configured with a field title generator would get e.g. 'ROOT' as its model title. Patch B guards this via `_attributes_set` and adds a test for it. Patch B also folds the root field's `deprecated` into the existing `__deprecated__` branch (handling the message-string and empty-string forms) rather than adding a separate block, and reuses the `__pydantic_root_model__` check already used later in the same function, removing the ad-hoc RootModel import. Its title precedence (config title > root field title > model_title_generator) is explicit and tested, whereas Patch A's ordering makes model_title_generator silently beat an explicit Field(title=...). Tests: B covers nested $defs usage, deprecated-as-message, title generator interactions, and config override; A's tests are reasonable but narrower. Scope and churn are comparable; B's small refactor is low-risk and clarifies the fix. B is the better fix.

Description

When declaring a RootModel and adding a Field annotation to the root property that includes examples, those examples are not part of the generated JSON schema. This also applies to the deprecated attribute. The title attribute is also not applied or it is overwritten by the class name of the root model class.

Most other attributes, such as pattern or description are exposed as expected. Furthermore, placing examples in json_schema_extra also works as expected.

Example Code

from typing import Annotated
from pydantic import RootModel, Field

class Foo(RootModel):
    root: Annotated[str, Field(examples=["foo", "bar"], deprecated=True)]

print(Foo.model_json_schema())  # does not include examples or deprecated.
