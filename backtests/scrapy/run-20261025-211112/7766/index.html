Idea: I assume that most of (especially older) utils were moved there to organize the Scrapy code, not to allow users to use those functions. Even if we currently don't plan to remove or break them it's useful to be able to freely do that in the future.

For the first pass the criteria are:

  • looking not at specific functions/classes but at whole modules;
  • a module must not have names mentioned in the docs;
  • deprecated names are ignored as if they don't exist;
  • undocumented names that are definitely used by e.g. scrapy-poet or 3rd-party code that I could find or look like they may be useful to other users are for now treated as to be kept.
