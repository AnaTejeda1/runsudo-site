Description

TemporalMCPServer.get_tools consults the instance-level _cached_tool_defs cache before deciding whether to schedule the get_tools activity. With cache_tools=True on the wrapped server (the default), a warm cache returns definitions and schedules nothing.

get_tools runs in workflow code while request parameters are prepared for each model step. The Temporal docs require the TemporalAgent to be defined at the top level of the module, since it is needed both inside the workflow and to register worker activities, so the instance and its cache are shared by every workflow execution in the worker process. Whether a workflow emits a get_tools activity command therefore depends on what has already run in that process. Temporal replay requires that decision to depend only on the workflow's own history. A history recorded with a warm cache fails replay on a cold process, and a history recorded cold fails replay on a warm process:

[TMPRL1100] Nondeterminism error: Activity type of scheduled event
'agent__<name>__model_request' does not match activity type of
activity command 'agent__<name>__mcp_server__<id>__get_tools'

Observed on 1.88.0. The relevant code is unchanged on 1.107.0 and current main, in both _mcp_server.py and _mcp_toolset.py.

How we hit it. A production ECS deploy replaced a worker while a 27-minute agent workflow was in flight. The workflow had started on a long-running worker with a warm cache, so its history contained no get_tools events. The first workflow task after the restart replayed the history on the fresh process, the code emitted a get_tools command where the history had a model request scheduled, and the workflow task failed with the error above. The workflow stayed Running with the workflow task retrying, and a parent workflow sat blocked on it through a peer-call activity. Both recovered about 40 minutes later, after fresh traffic warmed the new process's cache and replay matched again. Diffing our release ruled out changes on our side; we traced the divergence to the conditional emission in _mcp_server.py. Restarts aren't the only trigger: a history recorded on a cold process (the first run after worker boot) contains a get_tools event and fails replay on the same process after the shared cache warms, for example following sticky cache eviction.

Reproduction. The script below runs against a local Temporal server, records two turns on one TemporalAgent instance (turn 1 records get_tools, turn 2 records none), then replays turn 2's history with Replayer against a freshly constructed instance, which fails with the TMPRL1100 above. Replaying against the original warm instance passes. Production hit this through model_request_stream; the script uses the non-streaming model_request to keep the example small, and the mismatch is the same either way. The default PydanticAIPlugin sandbox passes pydantic_ai through without reloading, so the shared cache survives the sandbox in real deployments; the script uses UnsandboxedWorkflowRunner to keep itself self-contained.

Impact. Anyone running MCP toolsets under Temporal with the default cache_tools=True is exposed. The bug fires on any worker restart (deploy, crash, scale-in) while a multi-step workflow is in flight, and on same-process replays of the first run after worker boot. A stuck workflow retries its workflow task indefinitely and recovers only if the process cache drifts back into the state the history was recorded under. Since the error message talks about workflow code changes and versioning, it's easy to misdiagnose this as a deployment mistake on the user's side. Setting cache_tools=False makes every turn record the activity and restores replayability; that's the workaround we deployed.

Origin and possible fix. The cache was added in #4331 to address #4317. The simplest fix we can see: always emit the get_tools activity from workflow code, and cache the tool definitions inside the activity implementation, where replay consumes recorded results and process state is safe. A per-run cache would also work if it lives in state that replay reconstructs, such as graph run state; keying the shared cache by run id doesn't help, since entries survive the replay boundary. #4331 added the same cache to the DBOS wrapper, which probably deserves a look as well.

"""Repro: TemporalMCPServer's instance-level tool-defs cache makes workflow
histories non-replayable across worker restarts (TMPRL1100).

Connects to a Temporal server on localhost:7233, or starts a local test
server if that's unavailable. Requires: pydantic-ai, temporalio, mcp.
"""

import asyncio
import multiprocessing
import socket
import sys
import time
import uuid
from importlib.metadata import version

from pydantic_ai import Agent
from pydantic_ai.durable_exec.temporal import TemporalAgent
from pydantic_ai.mcp import MCPServerStreamableHTTP
from pydantic_ai.messages import ModelMessage, ModelResponse, TextPart
from pydantic_ai.models.function import AgentInfo, FunctionModel
from temporalio import workflow
from temporalio.client import Client
from temporalio.contrib.pydantic import pydantic_data_converter
from temporalio.worker import Replayer, UnsandboxedWorkflowRunner, Worker

GET_TOOLS_SUFFIX = "__mcp_server__dummy__get_tools"

# One TemporalAgent per worker process, shared by every workflow execution.
# Swapping the instance simulates a worker restart (fresh process, cold cache).
HOLDER: dict[str, TemporalAgent] = {}


def run_mcp_server(port: int) -> None:
    from mcp.server.fastmcp import FastMCP

    server = FastMCP("dummy", host="127.0.0.1", port=port, stateless_http=True, log_level="ERROR")

    @server.tool()
    def dummy_echo(text: str) -> str:
        """Echo the input text back."""
        return text

    server.run(transport="streamable-http")


def model_fn(messages: list[ModelMessage], info: AgentInfo) -> ModelResponse:
    return ModelResponse(parts=[TextPart("plain text, no tool calls")])


def make_temporal_agent(mcp_url: str) -> TemporalAgent:
    return TemporalAgent(
        Agent(
            FunctionModel(model_fn),
            name="repro_agent",
            instructions="You are a test agent.",
            toolsets=[MCPServerStreamableHTTP(url=mcp_url, id="dummy")],
        )
    )


@workflow.defn
class ReproWorkflow:
    @workflow.run
    async def run(self, prompt: str) -> str:
        result = await HOLDER["agent"].run(prompt)
        return result.output


def scheduled_activities(history) -> list[str]:
    return [
        ev.activity_task_scheduled_event_attributes.activity_type.name
        for ev in history.events
        if ev.HasField("activity_task_scheduled_event_attributes")
    ]


async def replay(history) -> Exception | None:
    replayer = Replayer(
        workflows=[ReproWorkflow],
        workflow_runner=UnsandboxedWorkflowRunner(),
        data_converter=pydantic_data_converter,
    )
    try:
        await replayer.replay_workflow(history)
        return None
    except Exception as e:  # noqa: BLE001
        return e


def error_text(e: Exception) -> str:
    parts = [f"{type(e).__name__}: {e}"]
    cause = e.__cause__
    while cause is not None:
        parts.append(f"  caused by {type(cause).__name__}: {cause}")
        cause = cause.__cause__
    return "\n".join(parts)


async def main() -> int:
    for pkg in ("pydantic-ai", "temporalio", "mcp"):
        print(f"{pkg}=={version(pkg)}")

    port = 18931  # fixed port for the local MCP server; change if taken
    proc = multiprocessing.Process(target=run_mcp_server, args=(port,), daemon=True)
    proc.start()
    env = None
    try:
        deadline = time.monotonic() + 15
        while True:
            try:
                socket.create_connection(("127.0.0.1", port), timeout=1).close()
                break
            except OSError:
                if time.monotonic() > deadline:
                    raise RuntimeError("MCP server did not come up")
                time.sleep(0.1)

        try:
            client = await Client.connect("localhost:7233", data_converter=pydantic_data_converter)
        except Exception:  # noqa: BLE001
            from temporalio.testing import WorkflowEnvironment

            env = await WorkflowEnvironment.start_local(data_converter=pydantic_data_converter)
            client = env.client

        mcp_url = f"http://127.0.0.1:{port}/mcp"
        task_queue = f"getools-repro-{uuid.uuid4().hex[:8]}"

        warm = make_temporal_agent(mcp_url)
        HOLDER["agent"] = warm
        histories = []
        async with warm:  # entered once at worker boot
            async with Worker(
                client,
                task_queue=task_queue,
                workflows=[ReproWorkflow],
                activities=warm.temporal_activities,
                workflow_runner=UnsandboxedWorkflowRunner(),
            ):
                for _ in range(2):
                    wf_id = f"getools-{uuid.uuid4().hex[:8]}"
                    await client.execute_workflow(
                        ReproWorkflow.run, "hello", id=wf_id, task_queue=task_queue
                    )
                    histories.append(await client.get_workflow_handle(wf_id).fetch_history())
        h1, h2 = histories
        a1, a2 = scheduled_activities(h1), scheduled_activities(h2)
        print(f"turn 1 activities: {a1}")
        print(f"turn 2 activities: {a2}")

        checks: list[tuple[str, bool]] = [
            (
                "turn 1 (cold cache) history records the get_tools activity",
                any(a.endswith(GET_TOOLS_SUFFIX) for a in a1),
            ),
            (
                "turn 2 (warm cache) history does NOT record get_tools",
                not any(a.endswith(GET_TOOLS_SUFFIX) for a in a2),
            ),
        ]

        # The bug: fresh (cold) instance replaying a warm-recorded history.
        HOLDER["agent"] = make_temporal_agent(mcp_url)
        err = await replay(h2)
        nondet = err is not None and "Nondeterminism" in error_text(err)
        checks.append(
            ("replay turn 2 vs FRESH (cold) instance fails with nondeterminism (the bug)", nondet)
        )
        if err is not None:
            print(f"\ncaptured replay error:\n{error_text(err)}\n")

        # Control: the same history replays fine on the still-warm instance.
        HOLDER["agent"] = warm
        err = await replay(h2)
        checks.append(("replay turn 2 vs original warm instance passes (control)", err is None))
        if err is not None:
            print(f"\nunexpected control replay error:\n{error_text(err)}\n")

        ok = all(passed for _, passed in checks)
        for label, passed in checks:
            print(f"[{'PASS' if passed else 'FAIL'}] {label}")
        return 0 if ok else 1
    finally:
        if env is not None:
            await env.shutdown()
        proc.terminate()
        proc.join(timeout=5)


if __name__ == "__main__":
    sys.exit(asyncio.run(main()))
