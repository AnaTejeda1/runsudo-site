Add FastMCP and MCP's python-sdk to third-party tests

Our patch was judged better than the merged fix.

In this judgment, Patch A = our agent, Patch B = the merged fix.

Both patches add `test-fastmcp` and `test-mcp-python-sdk` jobs and wire them into `create-issue-on-failure`, so both address the issue's ask. Neither adds tests, which is expected for a CI-config change.

**Patch A** is tightly scoped. It adds only the two new jobs. They follow the file's existing conventions: frozen `uv sync`, uninstall both `pydantic` and `pydantic-core`, then install both editable from the checked-out pydantic repo (`./pydantic-latest` and `./pydantic-latest/pydantic-core`). That keeps pydantic and its core in lockstep with the version under test. It mirrors FastMCP's own CI test selection. The one uncertainty is whether the `not integration_test` marker is still current.

**Patch B** also adds the two jobs, with some thoughtful touches: it unsets `FORCE_COLOR` for FastMCP's CLI tests, uses finer-grained markers, disables the MCP smoke tests, and adds Python 3.14. However:
- It uninstalls only `pydantic` and installs only `./pydantic-latest`. It never replaces `pydantic-core`, so the locked core can mismatch the pydantic under test, which undermines the purpose of the job.
- It drops `--frozen` from FastMCP's `uv sync`.
- It bundles substantial unrelated churn into the shared workflow:
  - rewrites the ODMantic checkout to a raw `git clone`;
  - appends a redundant `tests/` to the ODMantic `-k` command, which already passes `tests`;
  - adds a Redis service to the Polar job;
  - replaces Dify's install and test invocation;
  - appends `tests/` to Beanie, Polar, Django Ninja and FastDepends.

  These edits touch many other jobs, add risk of breaking them, and obscure the actual fix.

Given A's correct handling of `pydantic-core`, its consistency with surrounding jobs, and its minimal scope versus B's risky churn, A is the better patch.

The judge saw only the two patches, labelled A and B in random order, with issue links and version numbers removed. The reasoning above is shown verbatim.
