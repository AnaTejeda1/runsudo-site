Summary

Add a to_curl() method to scrapy.Request that turns the request into a curl cmd

Motivation

Request.from_curl() already exists, but to go the other way you have to use a separate function, scrapy.utils.request.request_to_curl() (added in 2.9 #5892)

When I'm debugging a spider with inspect_response(), I often want to run a request outside Scrapy — from the terminal or in tools like Postman. Today I have to remember the import path to use it, I forget it often enough that I end up looking it up in the source:

>>> from scrapy.utils.request import request_to_curl
>>> print(request_to_curl(request))

With a to_curl() method this is easier to find and matches from_curl():

>>> print(request.to_curl())
