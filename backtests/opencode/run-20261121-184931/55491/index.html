The issue

View on GitHub

Steps to reproduce

nix build github:anomalyco/opencode/v2.0.28#opencode

The build fails in the CLI's buildPhase:

error: Cannot find module '../../../script/native-arch' from '/build/source/packages/cli/script/build.ts'

What you expected

The flake at a release tag builds packages.opencode.

What happened instead

packages/cli/script/build.ts (new at 2.0.28) imports NativeArch from the monorepo root:

import { NativeArch } from "../../../script/native-arch"

but nix/node_modules.nix's src fileset union — which the CLI inherits via inherit (node_modules) version src — omits the root script/ directory, so the file isn't in the build tree.

Fix

Add ../script to the fileset union (one line). script/ is not a bun workspace, so the installed node_modules tree — and therefore the node_modules hash — is unchanged; only the CLI build gains the file it imports.

Context

Hit while packaging OpenChamber for Nix (openchamber/openchamber#4529 pins opencode at the release tags via this flake).
