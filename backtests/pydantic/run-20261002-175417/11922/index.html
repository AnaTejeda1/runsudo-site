Some Field attributes lost in JSON schema when using RootModel

Better

Our patch was judged better than the merged fix.

In this judgment, Patch B = our agent, Patch A = the merged fix.

Both patches fix the issue the same basic way: in the model-level schema update, they copy the `root` field's examples, deprecated flag and title into the RootModel's JSON schema, and both serialize examples with `to_jsonable_python`. For the issue's example (examples plus deprecated, and title no longer overwritten by the class name), both work.

Patch B is the cleaner and more complete version:
- It computes `root_field` once, using the existing `__pydantic_root_model__` convention. It then reuses it for the title, the description, the new examples/deprecated handling, and the existing `json_schema_extra` branch, so all root-field metadata goes through one path.
- Title precedence is principled: config title first, then field title, then `model_title_generator`, then the class name. An explicit field title is more specific than a generic generator, so it should win. In Patch A, the generator would silently override an explicit `Field(title=...)`, which partly reproduces the reported "title overwritten" problem.
- Patch B also handles the `deprecated=''` edge case, which Patch A's truthiness check misses.

Tests: both add tests that fail before the change and pass after it. Patch B's are more meaningful:
- `deprecated` given as a message string.
- Non-JSON example values (`date`), which exercises the `to_jsonable_python` serialization.
- Precedence between config title and generator title.
- A nested RootModel appearing in `$defs`.

Patch A's tests cover only the basic cases plus config-title precedence.

Scope is comparable, and Patch B's refactor of the existing branches is small and low-risk. Overall, B wins on correctness at the edges and on test quality.

Description

When declaring a RootModel and adding a Field annotation to the root property that includes examples, those examples are not part of the generated JSON schema. This also applies to the deprecated attribute. The title attribute is also not applied or it is overwritten by the class name of the root model class.

Most other attributes, such as pattern or description are exposed as expected. Furthermore, placing examples in json_schema_extra also works as expected.

Example Code

from typing import Annotated
from pydantic import RootModel, Field

class Foo(RootModel):
    root: Annotated[str, Field(examples=["foo", "bar"], deprecated=True)]

print(Foo.model_json_schema())  # does not include examples or deprecated.
